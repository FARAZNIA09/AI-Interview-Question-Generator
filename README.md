# AI Interview Question Generator

An AI-powered web application that generates interview questions and answers based on selected technologies and experience levels.

## Features

- AI-generated interview questions and answers
- Technology selection dropdown
- Experience level selection
- Dark/Light mode
- Spring Boot REST APIs
- React Frontend
- Gemini AI Integration

## Tech Stack

### Backend
- Java
- Spring Boot
- Gemini AI SDK

### Frontend
- React
- Axios
- CSS
